مراقبة الخادم

تُحمَّل البيانات فقط عند الضغط على «تحديث اللقطة» — لا طلب دوري لمستخدمي التطبيق. تشمل اللقطة: عملية Node والنظام، طابور المساعد، عدّادات طلبات الذكاء الاصطناعي منذ آخر تشغيل للخادم، واحجام ملفّات البيانات الرئيسية.

عرض JSON كاملاً 
اضغط «تحديث اللقطة» لعرض بيانات من الخادم.
